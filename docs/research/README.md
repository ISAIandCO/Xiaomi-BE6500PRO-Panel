# Материалы разработки

Здесь сохранены инвентарь API, сравнение прошивок и авторские заметки, на основании которых реализована панель 1.2.0. В заметках от 8–9 ноября 2026 года могут встречаться промежуточные ограничения и старые количества тестов; текущее поведение описано в корневом README и `../VERIFICATION.txt`.

| Файл | Содержание |
| --- | --- |
| `api-inventory.csv` | 656 зарегистрированных API прошивки 1.1.123, обработчики, параметры и происхождение; регистрация не гарантирует поддержку конкретным RD08 |
| `firmware-comparison.json` | Отличия маршрутов и хэши выбранных компонентов 1.1.96 / 1.1.123 |
| `network-contracts.txt`, `network-final-gaps.txt` | Сетевые команды, единицы измерения, неподтверждённые функции |
| `security-contracts.txt`, `security-service-auth.txt` | Политики безопасности, журналы, проверки доступа штатных служб |
| `security-miio-transport.txt`, `security-miio-udp-feasibility.txt` | Ограниченный miIO-транспорт и условия Bluetooth RPC |
| `system-contracts.txt`, `system-file-evidence.json` | Системные операции, форматы файлов и офлайн-проверка официальной прошивки |
| `plugin-contracts.txt`, `PLUGINS-AND-GAPS.txt` | Форматы подписанных плагинов, цепочка доверия и ограничения SDK |

Исходники панели перенесены из прежней папки `6500pro_router-panel/` в корень этого репозитория. Собственный пример плагина находится в `../../examples/rd08-status/`. Исторические ссылки на `research/*.asm`, `.lua`, выгрузки, SDK и вспомогательные исследовательские скрипты обозначают исходные локальные доказательства; эти файлы не распространяются здесь. Сырые ответы реального устройства и личные конфигурации не публикуются. Сводка проверок перенесена в `../VERIFICATION.txt`, вместо исходного `REPORT.txt`.

Исследование не давало разрешения на прошивку, сброс или включение root/SSH; такие операции на устройстве при проверке не выполнялись. Чтения и предпросмотры не считаются проверкой записи.
