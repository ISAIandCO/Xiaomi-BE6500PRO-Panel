Встроенный Hosts — что именно обнаружено

пустой rootPath. init.d/pluginmanager копирует этот JSON в installPlugin.
Это встроенная запись каталога, а не свидетельство установленного стороннего
исполняемого файла. Настройки доступны отдельным service/internal:

custom_host_set: поле hosts = JSON-массив строк, например
  ["192.168.31.2 printer.lan","2001:db8::2 device.example"]
pcall-прототип содержит decode(trim(hosts)); наружный цикл pairs применяет
регулярное выражение IP+имя, пишет /etc/custom_hosts, копирует /tmp/hosts/custom_hosts
и перезапускает dnsmasq. Пустой массив очищает записи. Запись — не безвредное
чтение: изменяет разрешение имён всей сети и кратко перезапускает DNS/DHCP.

Загрузка через /uploadfile/cgi-bin/... использует UPLOADFILE nginx.
Локальный путь — /tmp/uploadplug.mpk; extractPlug вызывает:

Далее pluginLocalInstall отправляет datacenter API602 с

Это не универсальная установка ZIP/IPK/APK или выполнение shell-команд.
В обработчике нет фиксированного размера: вызывается checkSpace. Шаблон

init nginx меняет default-locations.conf по UCI client_max_body_size=100M.

Внешняя оболочка HDR1 — проверена по mkxqplugin
0x1ef8 выбирает -X/mode9 ->0x3880 ->проверка0x304c ->RSA0x4654.
Флаг -F устанавливается0x1ee4 и выбирает plugin_public.pem в0x4434..4460.
-F НЕ отключает подпись. Корень — фиксированный открытый RSA1024-ключ Xiaomi.
HDR1 header48 байт: magic HDR1, u32signatureOffset@4, rawCRC32@8,
hardware/flags@12, до8 u32sectionOffsets@16..47.
Plugin metadata56 байт@48: minVersion3*u32, maxVersion3*u32, ASCII model32.
Модель сравнивается точно; три компонента версии проверяются независимо,
а не обычным лексикографическим сравнением семантической версии.
Секция: u16magicBABE@0, u32size@8, filename32@16, payload@48.
Подпись: length@signatureOffset, signature@signatureOffset+16;
RSA-SHA1 покрывает bytes12..signatureOffset. CRC — raw IEEE CRC32 с initial
0xffffffff и БЕЗ финальной инверсии над bytes12..EOF (mkxqplugin0x429c..43ec).
В режиме -F извлечённый файл переименовывается в unified_plug.mpk
(0x3638..366c). Несколько секций неоднозначно перезаписывают этот путь;
проверка панели поддерживает только одну секцию с вложенным MIPK.

Внутренний MIPK — проверен по pluginmanager
verify_load_mpk0x556c; verify_check_header0x5048; verify_check_sign0x52b4.
u32magic0x4b50494d ('MIPK')@0; standardCRC32@4 надbytes8..EOF;
u32kind@8 допускается0/1; u32signType@12 в текущем менеджере требуется1.
u32payloadLength@16; ZIP payload@20;
затем u32certificateLength, certificateBytes;
затем u32signatureLength, signatureBytes. Итоговый размер должен совпадать.
RSA-SHA1 в0x54b0..54fc использует X509_get_pubkey из фиксированного
app.miwifi.com.ca.crt; digest bytes8..конецcertificateBytes, без поля длины
подписи и самой подписи. EVP_VerifyFinal должен вернуть1, иначе ошибка.
Точные GOT-импорты: 0x1ec48 X509_get_pubkey, 0x1ed10 EVP_DigestUpdate,
0x1ed48 EVP_VerifyFinal, 0x1ee80 EVP_sha1.
CA self-issued MIWIFI/Xiaomi.com, RSA2048. Срок2014-03-28..2024-03-25.
Исследованный код извлекает публичный ключ, не проверяет срок сертификата.
Сторонний сертификат eMudhra не заменяет этот ключ или plugin_public.pem.

Manifest и среда
Внутри ZIP требуется manifest в корне. После установки он находится в
/userdisk/appdata/APPID/etc/manifest. supported_rom сравнивается с
/etc/config/pluginmanager: miwifi_rom_2. Текущий sdk_level=5.
Проверка0x7a44..7ab4 отклоняет запрошенный SDK6..99; значения>99 — отдельный
vendor-special путь. Обычный авторский пример использует5.
Версия/name/plugin_id нужны для списка и идентификации. plugin_class
дополнительно проверяет совместимость (для game есть запрет другого game).
start_script — DSL MKDIR/RUN. Legacy RUN управляется менеджером; более
новый run executable может принимать start/stop/restart/uninstall.
Нельзя путать этот framework с полноценным root-доступом или opkg.

Native lifecycle IDs (внутри pluginmanager; transport нужно подтверждать)
600: инициализация менеджера, НЕ диагностический read.
601: список, используется подтверждённым xqsystem/installed_plug.
602: локальная установка, pluginPath; поддержан кодом pluginLocalInstall.
603: иной режим установки, не раскрывать без подтверждённого контракта.
604: прогресс, поле ids — строка IDs через ';', каждый ID до31 символа.
605: удаление, pluginID; запускает uninstall и удаляет каталог.
606: смена статуса, pluginID и status. Допустимы5/6/7. По веткам кода:
5 — включён,6 — вручную выключен,7 — остановлен менеджером задач.
При старте datacenter его init-script переписывает сохранённые7 в5.
Переход5->6/7 вызывает stop,6/7->5 — restart; факт процесса надо проверять.
609: иной режим установки/обновления, без подтверждения не использовать.
610: дополнительный control handler, не произвольный shell.
666: чтение package info, может создавать временный файл; контракт не завершён.

Проверка панели
inspectPluginPackage(Buffer,{hardware,firmware}) не извлекает файлы на диск.
Проверяет HDR1/MIPK, обе подписи/CRC, модель/ROM/SDK, ZIP paths/links/duplicates/
overlaps/размеры/CRCmanifest. Лимит48МиБ вход,128МиБ суммарно распаковано,
4096 entries,64КиБ manifest. Возвращает uploadable только для проверенного
односекционного HDR1. RawMIPK можно исследовать, но не отправлять этим путём.
5 тестов доказывают отрицательные/структурные случаи и различие CRC-форматов.
При отсутствии настоящего подписанного образца положительное принятие
пакета и реальная установка на RD08 НЕ проверены.
