# Настройка и разработка

## Локальная конфигурация

`Setup.cmd` / `npm run setup` создаёт `router-config.json` после сравнения сертификата с показанным в браузере. Пароль при настройке не запрашивается; до подтверждения выполняется только TLS-соединение без логина и HTTP-команд.

Существующий файл не перезаписывается. Для повторной настройки остановите панель, переименуйте `router-config.json` и запустите настройку снова. При смене LAN-адреса измените `host`; при смене сертификата проверьте устройство и повторите настройку.

Для ручной настройки скопируйте [router-config.example.json](../router-config.example.json) в `router-config.json`, укажите свой адрес и настоящий SHA-256 сертификата. Заглушка из примера для подключения не подходит. `port` — локальный порт панели. Не меняйте `writeFirmware` для обхода режима только чтения.

`router-config.json` исключён из Git. Не добавляйте его, резервные копии, журналы или сетевые дампы в коммиты.

## Тесты

Требуется Node.js 22 или новее. Зависимостей для установки нет.

```sh
npm test
```

Тесты используют вымышленные ответы и локальные серверы. Тестовые пароли, токены, IP- и MAC-адреса не относятся к реальной сети. Открытые ключи Xiaomi и константы протокола нужны для проверки форматов и не являются пользовательскими секретами.

## Демонстрация

```sh
node test/preview.mjs
```

Откройте `http://127.0.0.1:18651`, пароль — `panel-test`. Демонстрация работает с вымышленными данными без подключения к роутеру. Остановка — `Ctrl+C`.

## Структура

Обработчики панели находятся в корне репозитория, интерфейс — в `public/`, тесты — в `test/`. [Материалы исследования](research/README.md) описывают контракты штатного API и ограничения; [отчёт](VERIFICATION.txt) отделяет проверенные чтения и предпросмотры от операций, которые не выполнялись на оборудовании.
